Holo4: Computer-Use Agents With Named $/Task — 27B Dense, 35B-A3B MoE, Open Trajectories

28 September 2026 · Anpoo Sivanadi · based on H Company’s Sep 28 Holo4 newsroom, HF blog, and Holo4-27B / 35B-A3B cards

H Company Holo4: 27B dense + 35B-A3B MoE computer-use VLMs with named OSWorld / AutomationBench $/task and open trajectories — no AA Index row, and a CC BY-NC vs Apache-2.0 license split you should write into the routing ticket.

Last night’s AliceAI-Foundation-80B note was a from-scratch base: 80B / 3B, KDA:GA 3:1, WikiWebFacts / HardMultiQA. Yesterday’s DeepSeek-V4.1-Flash and MiMo-V2.6-Pro pieces were API KV math and an open-weights AA 46 price floor. This morning is a different purchase: a generalist computer-use agent that clicks, types, runs code, and calls MCP or business APIs from one model — with published cost per task, not just pass rates. On September 28, 2026, H Company shipped Holo4.

What actually changed for people who run agent fleets

The durable product change is one model across GUI, code, MCP, and API with a published score × $/task table and open evaluation trajectories.

Most agent stacks still pick a lane: a GUI specialist that dies without a screenshot, or a tool-calling model that stalls when the app has no API. Holo4’s pitch is that a real task mixes those modes — FreeCAD + shell + MCP in one session — and the same checkpoint should run on desktop, web, Android, code sandbox, and business APIs without swapping models.

Training stack (newsroom): Agentic Task Factory ~10,000 tasks (~4k web, ~3k MCP, ~3k desktop/OS), including hybrid GUI+MCP environments. SFT on 127B tokens (~¾ successful agentic trajectories: desktop 45%, web 14%, MCP/API 12%, mobile 3%). Then two asynchronous online RL LoRA experts (desktop/web vs terminal/MCP/API) merged at equal weight. They also rebuilt the harness (memory across hundreds of steps; shell on the desktop) and publish the OSWorld 2.0 climb from Aug 10 6.1% to release 61.7%. Trajectories behind the public scores are open — replay at trajectories.hcompany.ai or pull Hcompany/trajectories.

Holo4 does not claim an AA ceiling. It argues that a mid-size VLM with published GUI+code+MCP cost tables and open traces is a better agent-fleet canary than guessing which chat flagship still works when the app only has a screen.

Caveats I would write into any Holo4 ticket

  1. Harness ≠ model. Scores are Holo4 inside hai-agents. Swap the loop and the number moves — reproduce before you retire a Sol / Opus path.
  2. License split is real. 35B-A3B is Apache 2.0; 27B is CC BY-NC 4.0. Self-host commercial fleets should start on the MoE card unless counsel clears NC.
  3. OSWorld ≠ OSWorld 2.0. Short-task 85.2% is not long-workflow 61.7%. Quote the row you mean.
  4. AutomationBench public set overlaps training data (480/600). Prefer held-out 120 (49.3% for 27B) or wait for private-set.
  5. No AA Index in this drop. Keep MiMo Pro on the open Intelligence Index floor.
  6. Not a rematch of Inferra / Leo X / Lessengers / Continuum. Those are memory and optics. This is an agent model + harness ticket.
  7. Frontier foils are mixed harnesses. Opus / Astra / Fable $/task rows are order-of-magnitude, not a controlled bake-off.

How I would evaluate if I ran computer-use or MCP fleets

  1. API canary on H Models at published rates — your $/task on a fixed OSWorld 2.0 / AutomationBench subset before any weight download.
  2. Self-host Apache 35B-A3B (BF16 → FP8/NVFP4 as memory allows) behind hai-agents or your loop; keep 27B as research/NC only.
  3. Replay Hcompany/trajectories on failing tasks to separate harness bugs from weights.
  4. A/B against Qwen3.8 27B on the same harness, and against Sol / Opus 5.5 on the hard unattended subset where $/task still loses to closed max-effort.
  5. Keep AliceAI for post-train substrate and MiMo / Flash for chat/API volume — Holo4 is the computer-use board.

This is a computer-use agent release with named OSWorld / AutomationBench $/task, dual licenses, and open trajectories — not a new closed flagship and not an AA rematch. Put Holo4 where you need GUI + code + MCP in one mid-size VLM with a readable cost table. Keep MiMo on the open ceiling/price row, DeepSeek-V4.1-Flash on cacheable API loops, AliceAI on from-scratch bases, and Astra / Opus 5.5 on hard unattended work until your harness says otherwise. Measure, then move traffic.
