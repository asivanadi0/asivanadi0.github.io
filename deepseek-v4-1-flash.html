DeepSeek-V4.1-Flash: 890 Bytes of KV per Token — and Why V4-Pro Is Being Retired

27 September 2026 · Anpoo Sivanadi · based on DeepSeek’s Sep 10 V4.1-Flash release and Artificial Analysis / Powerdrill reads

DeepSeek-V4.1-Flash: 890 bytes KV/token, 8B prefill / 16B decode MoE, MIT weights, V4-Pro traffic steered to Flash rates — AA Index 39, with a Terminal-Bench 4.0 gap vs Opus/Sol on DeepSeek’s own table.

Last night’s MiMo-V2.6-Pro note was an open-weights price-floor sentence at Artificial Analysis 46. This morning is the other half of the same routing problem: what the model does to HBM and SSD when the agent loop is input-heavy. On September 10, 2026, DeepSeek shipped DeepSeek-V4.1-Flash — a multimodal MoE under an MIT license — and started retiring the previous Flash / Vision-Exp endpoints onto it. By mid-September, legacy deepseek-v4-pro traffic was also being steered to Flash rates until V4.1-Pro lands.

Primary sources: DeepSeek’s Sep 10 release note, Hugging Face model card, API Models & Pricing, Artificial Analysis release page, and Powerdrill’s Sep 14 pricing cross-check. Vendor benches below are DeepSeek’s unless marked independent (Artificial Analysis). Distinct from the pending DeepSeek × Ascend 950DT cluster package.

Same-stack foil from last night: MiMo-V2.6-Pro sits at AA 46 and $0.435 / $0.87 list with a deeper open-weights ceiling claim. Flash is not trying to win that ceiling row. It is trying to win the cache and activate row on long agent prompts.

What actually changed for people who run agents

The durable product change is not a new FLOPS sticker. It is asymmetric activation + a smaller persistent KV.

CED projects the decoder’s global KV from the encoder’s final hidden states instead of building a full per-layer KV stack in the decoder. Prefill therefore activates 8B; decode activates 16B. That is the input-heavy agent sentence: attach a long repo or tool trace once, then ask several questions without lighting up a Pro-class activate path on every prefill token.

CSA2 and FP4 main-KV caching push the published global cache to 890 bytes per token. DeepSeek’s release note translates that into capacity: about one-quarter the HBM and one-eighth the SSD versus V4-Flash. If you already read Lightbits Inferra, keep the layers straight: Inferra is system orchestration across HBM/DRAM/NVMe; V4.1-Flash is model compression of what must sit there.

Operationally, DeepSeek is also cleaning the SKU sheet. V4-Flash and V4-Flash-Vision-Exp are retired onto deepseek-flash. Starting 04:00 UTC on September 14, 2026, deepseek-v4-pro requests were routed to V4.1-Flash at Flash rates until V4.1-Pro ships. That is a fleet routing ticket, not a marketing footnote.

Flash does not invent a fabric. It argues that long-context agent loops should not pay V4-Pro prices for a worse activate/cache shape — and DeepSeek is forcing that migration in the API.

Caveats I would write into any Flash ticket

  1. Reproduce Terminal-Bench 4.0 / DeepSWE / your repo harness before you delete a Pro shadow route — DeepSeek’s table is not your fleet.
  2. Do not paste “beats Opus 5.” Flash leads some of DeepSeek’s own agent rows and still loses hard boards; Opus 5.5 is also newer than the Opus-5.0 column.
  3. Peak vs off-peak is real money. Weekend and CN-holiday hours are off-peak; weekday UTC mornings are not. Batch flexible work off-peak.
  4. Self-host ≠ free. Weights are MIT; the card points at a conversion/inference path and notes there is no Jinja chat template — use DeepSeek’s encoding reference or deepseek-recipe.
  5. AA 39 ≠ MiMo 46. Route ceiling work to MiMo Pro, Astra, or Opus; put Flash where cache-hit agent loops dominate the bill.
  6. Not a rematch of Inferra / Leo X / Lessengers. Those are system memory and optics. This is the model serving layer.

How I would evaluate if I ran agent fleets

  1. Cost per completed task on deepseek-flash at peak and off-peak vs MiMo Flash/Pro, Sol, and Luna — include cache-hit share.
  2. HBM / SSD footprint on your longest production contexts against the 890 bytes/token claim; do not trust the slide alone.
  3. Terminal-Bench 4.0-class unattended jobs on a shadow route before you collapse Pro traffic.
  4. Effort dial 1–100 as a budget control, not a quality slogan — measure which integers actually move your suite.
  5. Keep a closed fallback (Opus 5.5 / Astra) for the boards where DeepSeek’s own card shows the gap.

This is a KV-and-activate efficiency release with MIT weights and a forced SKU cleanup, not a new closed flagship. Put Flash on long, cacheable agent loops where $0.15 / $0.60 off-peak and a smaller persistent cache beat V4-Pro arithmetic. Keep MiMo Pro on the higher open ceiling, and keep Astra / Opus 5.5 on hard unattended work until your harness says otherwise. Measure, then move traffic.
