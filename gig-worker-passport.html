Project

Gig Worker Passport

github.com/asivanadi0/gig-worker-passport

A decentralized system for verifying gig worker credentials using blockchain.

What it is

Gig Worker Passport is an open-source project for issuing and verifying gig worker credentials on-chain. The public README describes a FastAPI backend alongside Solidity contracts managed with Hardhat.

Stack

  • FastAPI backend
  • Solidity smart contracts
  • Hardhat for compile, test, and deploy

The repository includes CI workflows for linting, tests, and contract compilation, plus CD workflows for deploy.

Scope

This page tracks the public repository. It does not claim production users or live deployments.
