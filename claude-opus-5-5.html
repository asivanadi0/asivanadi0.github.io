Claude Opus 5.5 — Fable-class work at $4/$20, and the fallback-safeguard asterisk.

Last night’s GPT-6 Sol and Luna note ended with an explicit asterisk: Anthropic shipped Claude Opus 5.5 about ninety minutes earlier, and OpenAI’s cost charts still showed Opus 5 / Fable 5.1. Tonight is that rematch — what you actually route against GPT-6 Astra and Sol once the Claude 5.5 family is on the invoice.

Primary sources: Anthropic launch (Sep 22, 2026), Opus 5.5 overview docs, Digital Applied’s Opus 5.5 vs Astra comparison. Specs and vendor benches are Anthropic’s unless marked independent (Vals AI / Zapier / Digital Applied’s read of both tables).

Astra stays $10 / $50, and prompts with >272K input bill the whole request at $20 / $75. Opus 5.5 keeps $4 / $20 across its full 1M window — that line alone is why last night’s Sol/Luna post said to re-check Claude before claiming an Anthropic cost win.

What changed for people who run agents

The durable product change is not a new FLOPS sticker. It is list price + token efficiency + safeguard semantics.

Anthropic’s case is Fable-class work cheaper than Opus 5: fewer tokens per task at a lower rate card, with clearer writing that early testers said cut rework. Mid-conversation effort changes can keep the prompt cache (per-message effort beta) — the same agent-shaped cache question as Sol/Luna, different SDK: cost per completed task.

The unattended-loop asterisk: when a cyber or biology safeguard fires, the request falls back to another Claude model and continues. Digital Applied contrasts that with Astra’s API, where monitoring can stop the task. Fallback keeps work moving and changes which model wrote the diff; a hard stop audits cleanly and breaks the run. Plan for the behavior you chose.

Anthropic’s own cost-efficiency claims on that table: at default effort, Opus 5.5 beats Astra on FrontierCode at roughly 20% of the cost per task and matches Astra on Terminal-Bench 4.0 for about 40% of the cost. Treat those as vendor $/task until you reproduce them.

Fine print that belongs in a routing ticket:

  1. AutomationBench was run by Zapier without fallback models, so safeguard interventions counted as failures — Anthropic says that lowers the score versus production.
  2. On Terminal-Bench / science benches, cybersecurity and biology tasks that hit safeguards completed on Opus 4.8 / Opus 5 respectively in Anthropic’s setup — that can cut Opus 5.5’s printed score.
  3. Standard errors are material: Terminal-Bench ±2.6 pts for Opus 5.5; Terminal-Bench-Science ±3.5–5 pts.
  4. Digital Applied’s cross-read: Opus leads Terminal-Bench / GDPval / HLE by margins larger than harness noise; Astra leads AutomationBench and Terminal-Bench-Science; FrontierCode is within noise. Vendor harnesses disagree by up to 5.4 points on the same Claude model (Opus 5 on FrontierCode: Anthropic 48.0% vs OpenAI 53.4%). Gaps under ~five points are unresolved until your harness says otherwise.

Opus 5.5 does not move KV blocks and does not invent a fabric. It argues that most long coding / knowledge-work agent loops should not burn Astra tokens, and that Claude’s invoice is finally competitive with Sol on the tasks you actually care about — if your eval agrees.

Caveats I would write into any Opus 5.5 ticket

  1. Reproduce Terminal-Bench / FrontierCode / your repo harness at fixed effort before you price a SKU — vendor $/task uses Anthropic’s research environment.
  2. Plan for fallback. Cyber/biology safeguards can silently change which model finished the turn; log model id per step.
  3. Astra still leads some lanes (AutomationBench, Terminal-Bench-Science on vendor tables). Do not paste “Opus wins everywhere.”
  4. Harness noise. Treat sub-~5 point gaps as unresolved (Opus 5 FrontierCode: Anthropic 48.0% vs OpenAI 53.4%).
  5. Vals SRE fallback rate. Runs that route refusals to older Opus models are not pure Opus 5.5 scores.
  6. Fast mode is 2× price. Latency tool, not the default fleet rate card.
  7. Sonnet/Haiku 5.5 are not out yet. Do not assume the whole ladder prices like Opus.

How I would evaluate the claim if I ran agent fleets

Pick twenty real tasks (migrations, overnight unattended jobs, one citation-checked knowledge pack). Run Opus 5.5, Astra, and Sol at medium and max. Log wall time, tokens, dollars per successful merge, fallback events, and rework minutes. Keep Fable 5.1 on a shadow route for a week. Promote Opus 5.5 only when cost-per-success and rework both move.

Bottom line

On September 22, 2026, Anthropic shipped Claude Opus 5.5 (claude-opus-5-5) at $4 / $20 with $0.20 cache reads, claiming Fable-class work at roughly 40% less cost than Opus 5. The durable facts for a systems reader are the named rate card (including no Astra-style >272K whole-request surcharge), the vendor leads on Terminal-Bench / GDPval / HLE, Astra’s remaining leads on AutomationBench and Terminal-Bench-Science, Vals AI’s nearly-level broad index with long-task edges, and the fallback safeguard contract you must design for.

That is enough to re-open the routing ticket last night’s Sol/Luna post left open. It is not enough to freeze a fleet default without your own twenty-task bake-off.
