Project

Financial Sentinel

Co-created with Prashant Gupta · GitHub · project page

Real-time financial risk monitoring using X API and Grok. Watches banks, exchanges, wallets, and trading platforms for institution-specific risk signals that show up on social media before they hit traditional news.

Problem

During the 2023 banking crisis, Silicon Valley Bank collapsed in about 48 hours. Warning signs appeared on X hours before mainstream coverage. Retail investors and customers who were not watching social media had no early signal.

Institution-specific risk often spreads on social media first: an exchange freezing withdrawals, a trading app halting orders, unusual activity at a bank. Nobody has time to watch dozens of institutions around the clock.

Approach

Financial Sentinel is an early-warning system that monitors financial institutions in real time, analyzes sentiment with Grok, and surfaces risk findings with evidence. It tracks institutions across banks, crypto exchanges, wallets, stock trading platforms, robo-advisors, payment apps, and neobanks.

The pipeline:

  • Fetches live posts from X API v2 (search, counts, and user lookup)
  • Scores viral risk from engagement velocity, verification status, and influence
  • Runs Grok sentiment analysis with grounded citations back to source posts
  • Streams progress over Server-Sent Events so the UI updates stage by stage
  • Sends Slack alerts for medium and high risk findings

Resilience patterns include a circuit breaker around external APIs, exponential backoff, and a Grok live-search fallback when rate limits hit. Every finding keeps direct post URLs for verification.

Result

A working FastAPI backend and Next.js frontend that can analyze an institution end to end: fetch posts, compute volume trends, run Grok analysis, and return a structured risk level with evidence. The chat UI is built with CopilotKit.

Stack: FastAPI, X API v2, Grok, Next.js, CopilotKit.
